# Kanban

Findings from the pre-launch review, in the order they were found. Each row was
proved from code, a failing test, production logs, or live production
infrastructure before it was written down — and several were **disproved** the
same way and are recorded as such rather than deleted.

This file exists because the list used to live only in a conversation. Six rows
(L-20, L-38 through L-42) were reconstructed from later summaries after the
earlier record was compacted away, which is the argument for the file.

**Status counts:** 160 fixed · 3 blocked on something outside the code ·
3 deliberately unchanged · 2 not a bug · 1 unrecoverable (L-20). 169 rows.

L-47 is no longer open: L-114 shipped the `openh264` bump in v0.1.9 and the row
was simply never updated — counting from the rows is what caught it.

Counted from the rows rather than kept by hand — the previous header said
"3 not a bug · 7 blocked", which folded L-47 (open, not blocked) and L-20
(unrecoverable) into categories they do not belong to. A tally that drifts from
what it is tallying is the failure this file was created to stop.
